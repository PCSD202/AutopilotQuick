Deployment secrets and provisioning packages now come from a password-encrypted archive. The app uses a cached encrypted bundle offline and waits for connectivity when no bundle is available. The watchdog starts before unlock and never asks for the password.

Download `AQ.SecretArchive.Tool.zip` and extract the entire folder to create or update a bundle. See [the archive guide](https://github.com/PCSD202/AutopilotQuick/blob/master/docs/secret-archive.md) for the required entries and deployment steps. GitHub release downloads remain public and require no GitHub credentials.

The development drive helper publishes a fresh build and can copy an encrypted bundle while preserving existing drive data. Startup text is white for readability.

Historical commits and release notes have been retained, with sensitive resources and hard-coded secret values removed. Historical release downloads containing those resources have been withdrawn. Existing clones should be replaced with a fresh clone of the rewritten history.
