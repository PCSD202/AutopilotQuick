The secret unlock window now stays above ordinary windows, keeping the password prompt visible during startup.

This release includes the encrypted bundle support introduced in v2.0.0. Download `AutopilotQuick.zip` for the app, or extract the entire `AQ.SecretArchive.Tool.zip` folder to create or update an encrypted bundle. See [the archive guide](https://github.com/PCSD202/AutopilotQuick/blob/master/docs/secret-archive.md) for deployment instructions.
