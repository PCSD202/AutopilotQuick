Fixed the take-home BIOS settings failure by invoking Dell CCTK directly with separate native arguments when clearing the setup password. This preserves the password exactly and removes the PowerShell wrapper from that operation.

BIOS failures now show the process exit code, and launch failures show the Windows error code, without exposing the password or command output. The update was confirmed working in a take-home imaging test using dev build 2.0.2.1. Automated tests on .NET 6 and .NET 10 use a fake native executable to verify argument handling without accessing BIOS hardware.
